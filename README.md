# B.Tech AI&DS Curriculum Audit & Process Automation Submission

## Repository Overview
This repository contains the complete two-part submission for the B.Tech Artificial Intelligence and Data Science (AI&DS) program evaluation at ICFAI Tech:
1. **Task 1 (`/Parking check-in automation`)**: An operational workflow investigation, time-and-motion audit, ROI calculation, and automated redesign of the campus parking check-in system.
2. **Task 2 (`/Curriculum audit`)**: A comprehensive 8-semester curriculum audit, 22% modernization proposal benchmarked against real enterprise job descriptions, an AI-assisted lab exercise log, and an interactive course/credit explorer.

## Limitations & Scope
* **Institutional Scope:** The curriculum audit represents an independent student-led program evaluation and optimization proposal; it does not constitute an officially ratified university syllabus modification.
* **Workflow Simulation:** Task 1 workflow improvements and synthetic test cases are modeled through functional specifications, time-motion formulas, and validation matrices rather than a live-deployed enterprise software cluster.
* **Data Privacy:** In accordance with compliance guidelines, all field studies and synthetic cases utilize anonymized operational metrics without collecting personal identities, student IDs, or restricted records.
